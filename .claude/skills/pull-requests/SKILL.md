# GitHub Pull Requests

## Opening and updating

- A request to open a PR, made at the start of a session, means you own git for that work: branch, commit, push, and open the PR yourself.
- Don't subscribe to the PR's events unless the user asks for it.

## Review comments

- Once your changes address a review thread, resolve it.
- To discuss an approach or decline a suggestion, reply in that comment thread on GitHub, not only in the chat.
